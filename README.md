# 🎯 Smart Event Dashboard

## 📌 Project Overview

The **Smart Event Dashboard** is a web-based application developed using **HTML, CSS, and Vanilla JavaScript**.  
It allows users to create, view, manage, and delete events dynamically using DOM manipulation techniques.

This project is part of **Lab Assignment 1** for the course **Web Development II (Advanced JS & React)** and focuses on understanding core JavaScript concepts without using any external libraries or frameworks.

---

## 🛠️ Technology Stack

- **HTML5** – Page structure
- **CSS3** – Styling and layout
- **JavaScript (Vanilla)** – DOM manipulation and event handling

> ❌ No external libraries or frameworks are used.

---

## 🎯 Features

✔ Add new events using a form  
✔ Display events as dynamic cards  
✔ Delete individual events  
✔ Clear all events at once  
✔ Add sample events  
✔ DOM manipulation demo section  
✔ Event delegation for efficient handling  
✔ Responsive and clean UI

## 📋 How to Use

### Add Event
1. Enter event title.
2. Select date.
3. Choose category.
4. Write description.
5. Click **Add Event**.

### Delete Event
- Click **X** button on any event.

### Clear All
- Click **Clear All Events** button.

### Add Sample Events
- Click **Add Sample Events** button.

### DOM Demo
- Type in input box.
- Text will change automatically.
